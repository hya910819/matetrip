# 메이트립 MATETRIP

로컬 맛집·핫플 체험단 플랫폼 **메이트립(MATETRIP)** — 운영: 그로스코리아 (GROWTH KOREA)

- 사이트: https://hya910819.github.io/matetrip/
- 빌드 원본: `index.html` (CSS·JS 인라인 단일 파일, 외부 의존 없음)

## 배포 방법

```bash
bash deploy.sh              # 재빌드 → main·gh-pages 푸시 → 접속 확인
```

GitHub Pages 게시 소스는 `gh-pages` 브랜치(`/` root)입니다. Pickle의 GitHub 앱 토큰에 Pages 설정 권한(`pages=write`, `administration=write`)이 없어 API로 `main` 소스로 바꿀 수 없기 때문에, `deploy.sh`가 `main`과 `gh-pages`를 같은 내용으로 함께 밀어 넣습니다. 나중에 저장소 Settings → Pages에서 Source를 `main / (root)`로 한 번 바꾸면 `gh-pages` 없이도 갱신됩니다.

## 구성 (2026-11-28 실사용 점검 반영)

- **체험단 둘러보기** — 캠페인 목록·상세, 신청서(방문 희망일시·동반 인원·연락처·채널 주소·신청 한마디·개인정보/노쇼 동의),
  마감·모집완료·등급미달·중복신청 차단, 로그인 후 신청서 자동 이어가기, 피크타임 제외 시간 검증
- **마이페이지** — 신청 내역, **선정자 가이드라인 모달**(확정 방문일시·주소·제외 시간·제공 내역·필수/배정 키워드 원클릭 복사·
  공정위 대가성 문구 복사·촬영 체크리스트·포스팅 D-day), 리뷰 제출 + 발행 후 인사이트 입력, 자동 검수 결과,
  수정요청 사유 확인 후 재제출
- **관리자** — 신청 관리(자동 매칭 점수 A/B/C 등급·A등급 일괄 선택·일괄 선정), **선정 모달에서 확정 방문일시·개별 키워드 배정
  + 선정 안내 문구 원클릭 복사**, 리뷰 검수(수정 사유 체크 + 비밀댓글 문구 복사), **포스팅 인사이트(일방문자·공감·댓글·사진·
  키워드 통합/블로그탭 순위) 입력 → 성과 보고서 즉시 반영**, 캠페인 가이드라인 편집, 성과 리포트, 크리에이터 풀
- **데이터** — Supabase를 연결하면 회원가입·신청·검수·인사이트가 실제 Postgres에 저장됩니다(미연결 시 데모/브라우저 저장).

배포 전 검증: `python3 verify.py`(PC 1440 · 태블릿 900 · 모바일 390, 122개 항목)와 `python3 check_schema.py`(컬럼 정합성).
